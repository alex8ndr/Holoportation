# HOLOPORTATION: Live 3D Object Capture and Transmission for CSA’s AR Astronaut Training


This project is an **open-source academic implementation** inspired by Microsoft’s concept of “Holoportation.” It enables real-time 3D telepresence by capturing, transmitting, and rendering a remote object as a live 3D object, aiming to make remote communication feel spatially immersive.
